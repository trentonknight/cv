## Development

### Building Locally

```bash
# Install dependencies
bundle install

# Build the site
bundle exec jekyll build

# Preview the site (requires Xcode command-line tools on macOS)
bundle exec jekyll serve
```

### Building for Production

```bash
bundle exec jekyll build --trace
```

## Color Scheme

This theme uses a **Deep Tech** color palette:

- **Deep Navy**: `#1A2E40` - Primary accent
- **Slate Teal**: `#2E5A5E` - Secondary accent
- **Tech Purple**: `#5A4E8C` - Tertiary accent
- **Soft Grey**: `#F2F2F2` - Background

These colors convey professionalism, security, and innovation - ideal for a DevOps/Platform Engineer profile.

---

## Customization

To modify the theme colors, edit the `_config.yml` file:

```yaml
deepnavy: "#1A2E40"
slateteal: "#2E5A5E"
techpurple: "#5A4E8C"
softgrey: "#F2F2F2"
```

To update content, edit `index.md` and modify the YAML frontmatter and content sections.
